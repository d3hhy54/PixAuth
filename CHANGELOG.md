## [2026-09-19]
### Added
- Добавлена функция `CryptoEngine::verify_password` для проверки паролей с использованием Argon2.
- Написан комплект из 5 модульных тестов, полностью покрывающих сценарии валидации (happy path, неверный пароль, невалидный хэш).

### Changed
- Рефакторинг модуля `crypto.rs`: логика переведена со строго процедурного подхода на объектно-ориентированную структуру `CryptoEngine`.

### Fixed
- Оптимизирована инициализация окружения: устранен избыточный вызов `dotenvy` в бывшей функции `get_params` (теперь `init`), благодаря чему конфигурация загружается строго один раз при старте сервера.

### Security
- Выявлена потенциальная уязвимость при использовании SHA512 для хэширования логинов; запланирован переход на HMAC-SHA512.
