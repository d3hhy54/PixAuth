## [2026-09-25]
### Added
- Реализован публичный API в структурах `SqliteRepository` и `DatabaseRepository` для чтения данных и внесения новых пользователей.
- Добавлена автоматическая генерация и запуск миграций базы данных при инициализации фабрики `DatabaseFactory`.
- Написан комплект из 4 модульных тестов, проверяющие корректную работу API `SqliteRepository`.

### Security
- Выявлена небезопасность и предсказуемость функции `split_by_parity` при разделении данных; запланирован рефакторинг алгоритма с переходом на криптографический генератор псевдослучайных чисел `ChaCha8Rng`.

## [2026-09-23]
### Added
- Заложена архитектурная основа интерфейса `DatabaseRepository` и фабрики `DatabaseFactory` для абстракции работы с хранилищем данных.

### Changed
- Оптимизирована инициализация окружения: вызов `dotenvy::dotenv().ok()` перенесен из внутреннего метода `CryptoEngine::init()` напрямую в функцию `main` для централизованной настройки приложения.

## [2026-09-20]
### Added
- Добавлены публичные функции `CryptoEngine::verify_user` для верификации пользователя на этапе криптографии и `CryptoEngine::hash_user` для высокоуровневого API получения хэшей.
- Написаны модульные тесты, полностью покрывающие публичный функционал структуры `CryptoEngine`.

### Changed
- Рефакторинг управления памятью: использование `Box::leak` для соли («pepper») заменено на `OnceLock`.
- Изменена архитектура: функции перенесены внутрь структуры `CryptoEngine`, обновлена логика геттера для тестирования движка.
- Повышена безопасность: метод хэширования логина изменен с SHA512 на HMAC-SHA512 с использованием секрета сервера (закрыта уязвимость от 19 сентября).

## [2026-09-19]
### Added
- Добавлена функция `CryptoEngine::verify_password` для проверки паролей с использованием Argon2.
- Написан комплект из 5 модульных тестов, полностью покрывающих сценарии валидации (happy path, неверный пароль, невалидный хэш).

### Changed
- Рефакторинг модуля `crypto.rs`: логика переведена со строго процедурного подхода на объектно-ориентированную структуру `CryptoEngine`.

### Fixed
- Оптимизирована инициализация окружения: устранен избыточный вызов `dotenvy` в бывшей функции `get_params` (теперь `init`), благодаря чему конфигурация загружается строго один раз при старте сервера.

### Security
- Выявлена потенциальная уязвимость при использовании SHA512 для хэширования логинов; запланирован переход на HMAC-SHA512.
